# Sakina · Méditer le Coran

Site statique (un seul fichier `index.html`) pour lire, écouter et méditer le Coran verset par verset.

- 114 sourates, recherche par nom/numéro et recherche plein texte dans la traduction
- Texte arabe uthmani, traduction française (Hamidullah), translittération, tafsir Al-Muyassar
- Récitation verset par verset (5 récitateurs), répétition 1 à 10 fois, enchaînement automatique
- Mode méditation : un verset à la fois, cercle de respiration, étapes du tadabbur, questions de réflexion, journal personnel
- Journal, favoris, reprise de lecture, progression, minutes par jour, jours consécutifs
- Thème nuit / sable, taille du texte réglable, export/import des données (.json) et export du journal (.txt)

Les données viennent de l'API publique AlQuran.cloud ; tout ce qui est personnel reste dans le navigateur (localStorage).

Pour l'essayer : ouvrir `index.html` dans un navigateur (connexion internet requise pour les versets et l'audio).
